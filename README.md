# Floristería Olivo — Web

Sitio estático construido con Vite + React + Tailwind.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar para producción

```bash
npm install
npm run build
```

Esto genera la carpeta `dist/` con el sitio estático listo para publicar
en cualquier hosting (Vercel, Netlify, GitHub Pages, un servidor propio, etc).

## Desplegar en Vercel

1. Sube este proyecto a un repositorio (GitHub/GitLab/Bitbucket) o importa
   la carpeta directamente en Vercel.
2. Framework preset: **Vite** (se detecta automáticamente).
3. Build command: `npm run build`
4. Output directory: `dist`

No hace falta ninguna variable de entorno.
